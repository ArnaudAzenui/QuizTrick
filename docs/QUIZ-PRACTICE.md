# Quiz practice behavior

Best-score badges compare all saved attempts for a study text, including regenerated quizzes. Tied top scores all receive the badge. Separate study texts remain separate topics even if their titles match.

Saving a task opens Add study text. Skip for now returns to tasks; the task has already been saved.

Every quiz starts with setup. Multiple attempts and hints is optional and applies to that run. Choice answers receive immediate server feedback. Short answers use Check answer so students can finish typing before grading. Failed checks can be retried without losing the answer. Hints rule out an incorrect choice or give the first letter and word count for short answers; true/false questions use a reading prompt to avoid revealing the answer outright.

Checks do not save attempts. Final submission uses the existing grading and storage path, and the final answers determine the recorded score, including corrections made with hints. Answer keys stay on the server until the results screen. No database migration is required.
