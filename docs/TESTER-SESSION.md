# External tester session sheet (F-5)

Owner: Fardin. Used in Week 14 with at least two students from outside the team (SOW 8.3).
Each session takes about 20 minutes. We watch and take notes; we do not help unless the tester is stuck for more than two minutes, and we write down when we had to.

## Before the session

- Tester has a QuizTrick account on https://quiztrick.vercel.app (they sign up themselves in task 1).
- For task 6: the QuizTrick extension is loaded unpacked in Chrome or Edge on the session laptop (see `extension/README.md`), and the tester is signed in to Canvas with a course page open.
- A short set of notes (a page of a textbook or class notes, at least 200 characters) is ready for task 2.

## Tasks (read each one out, do not show the steps)

| # | Task for the tester | Done unassisted? | Time | Notes |
|---|---|---|---|---|
| 1 | Create an account and log in. | | | |
| 2 | Add some study notes to QuizTrick (paste them, or upload a file). | | | |
| 3 | Make a 10-question quiz from those notes. | | | |
| 4 | Take the quiz, change one answer, and submit it. Find your score. | | | |
| 5 | Add a study task for today with an estimated time, then mark it done. | | | |
| 6 | **Extension:** you are on a Canvas page for one of your courses. Get that page's text into QuizTrick using the QuizTrick button in the browser toolbar, check it, and save it. | | | |

What a pass looks like for task 6: the tester clicks the QuizTrick icon, presses Send to QuizTrick, sees the Add study text page open with the title and text filled in and the "Imported from Canvas" note, and clicks Save study text.

## After the session

Ask, and write down the answers in their words:

1. What was the most confusing part?
2. Was anything slower than you expected?
3. Would you use the Canvas button instead of copy and paste? Why or why not?

## Findings

One line each: tester, task, what happened, how bad (blocker / annoying / minor), who fixes it.
